# Практика к уроку 3

## Задачи

- Создайте структуры `Order` и `Item`.
- Напишите функцию создания заказа. Неположительный ID должен возвращать ошибку.
- Напишите функцию `AddItem`, которая добавляет позицию в переданный заказ и
  возвращает `error` при некорректных данных. Обработайте `nil` вместо заказа,
  пустое имя позиции и отрицательную цену. Функция должна менять переданный заказ.
- Напишите функцию, которая считает сумму позиций заказа.
- Создайте `map[string]string` с человекочитаемыми названиями статусов.
- Добавьте тесты для проверочных сценариев.

## Проверочные сценарии

- Валидный заказ без позиций имеет сумму `0`.
- После добавления двух позиций сумма заказа равна сумме их цен.
- При некорректных данных функция добавления позиции возвращает ошибку,
  не паникует и не меняет заказ.
- Изменение независимой копии `Order`, включая её позиции, не меняет исходный заказ.
- Запись в заранее не созданную map должна быть исправлена через `make`.
