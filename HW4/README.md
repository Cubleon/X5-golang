# Практика к уроку 5: обработка ошибок

Продолжение сервиса уведомлений из HW3. Email и push имитируют отправку выводом
в консоль

## Запуск

Команды выполняются из корня репозитория:

```sh
go run ./HW4
go run ./HW4 -message "Ваш заказ доставлен"
```

Вывод по умолчанию:

```text
email Заказ #1 готов к выдаче
push Заказ #1 готов к выдаче
```

Проверка пустого ввода:

```sh
go run ./HW4 -message ""
```

Программа выводит ошибку в stderr и завершается с кодом `1`:

```text
Error: dispatch: empty message
Укажите непустое сообщение через -message.
```

При запуске через `go run` дополнительно выводится `exit status 1`.

## Проверки

```sh
go build ./...
go test ./... -v
go vet ./...
gofmt -l HW4/*.go
```
